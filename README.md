# THECORD — atualizações

Este repositório só guarda as versões publicadas do THECORD (aba **Releases**).
O THECORD instalado procura atualizações aqui e se atualiza sozinho.

Para instalar, baixe o instalador da [última versão](https://github.com/hgputz/THECORDUPDATES/releases/latest):

- `THECORD-Setup-<versão>.exe`
